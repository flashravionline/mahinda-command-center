# 🏫 Mahinda College Galle - Digital Event Command Center

> The official digital web platform built for Mahinda College, Galle to seamlessly manage college events, live sports scoreboards, flash announcements, digital gate pass reservations, and ticket verifications.

---

## 🌟 Key Features & Modules

1. **Dynamic Event Management & Ticketing System:**
   - Browse upcoming college events categorized by Sports, Academic, Cultural, and Religious activities.
   - Real-time event capacity tracking with automatic "Sold Out" status indicators.
   - Secure multi-step gate pass reservation flow with student/normal tier pricing.
   - Digital ticket generation with unique Ticket IDs and a dedicated printing/saving interface (`My Tickets`).

2. **Real-Time Sports & Flash Updates (`Updates` Page):**
   - Live cricket/sports scoreboard featuring active batting stats, run rates, and ball-by-ball over details.
   - Live Flash Announcements broadcasted instantly by school administrators.
   - Interactive Photo Highlights Gallery with a built-in fullscreen slideshow lightbox.

3. **Secure Administrative Control Center (`Admin Dashboard`):**
   - Comprehensive dashboard for administrators to publish, edit, or delete events and highlight galleries.
   - Real-time ticket sales monitoring and total revenue calculation per event.
   - Full live score controlling panel.

4. **Global Light / Dark Theme Support:**
   - Seamlessly toggle between a sleek Dark Theme and a clean Light Theme across the entire application with synchronized background styling.

---

## 🛠️ Technology Stack

- **Frontend:** React.js (Vite), Tailwind CSS
- **Icons:** Lucide React
- **Backend & Database:** Firebase Realtime Database & Firebase Authentication
- **Deployment:** Vercel
